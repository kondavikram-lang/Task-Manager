## Brand & Style
The design system embodies modern productivity: focused, frictionless, and visually serene. Targeted at professionals, knowledge workers, and organized individuals managing personal and work sprints, the interface emphasizes immediate cognitive clarity and tactile satisfaction. 

The aesthetic is Modern Minimalist infused with subtle depth: crisp typographic hierarchy, generous breathing room, layered white cards on ultra-soft tinted surfaces, and vivid focal accents that draw attention strictly to what matters next. The emotional impact is one of composed control, lightness, and momentum.

## Colors
The palette leverages a cohesive indigo core complemented by purposeful utility and priority hues:

- **Primary (`#4F46E5`):** Deep Indigo. Used for primary actions, selected navigation anchors, active filter states, and dominant key elements.
- **Secondary / Accent (`#6366F1`):** Electric Iris. Applied to floating interactive elements, task completion transitions, progress bars, and subtle state indicators.
- **Canvas & Surface:** Base canvas sits on `#F5F7FF` (soft indigo tint). Card surfaces are pure `#FFFFFF` to lift off the canvas with clarity.
- **Neutrals & Slates:**
  - Primary text: Slate 800 (`#1E293B`) for maximum legibility.
  - Secondary text / icons: Slate 500 (`#64748B`) for metadata, subtasks, and supporting counts.
  - Borders & Dividers: Slate 200 (`#E2E8F0`) for whisper-thin definition.
- **Semantic Priority System:**
  - **High:** Rose (`#F43F5E`) background tint (`#FFF1F2`), text (`#E11D48`).
  - **Medium:** Amber (`#F59E0B`) background tint (`#FEF3C7`), text (`#D97706`).
  - **Low:** Emerald (`#10B981`) background tint (`#ECFDF5`), text (`#059669`) or soft Blue (`#3B82F6`) background tint (`#EFF6FF`), text (`#2563EB`).

## Typography
Plus Jakarta Sans provides a friendly yet structured geometric presence, offering open counters that remain sharp on high-density mobile screens. 

- **Display & Headlines:** Tighter letter-spacing (`-0.02em` to `-0.03em`) creates unified, punchy titles for daily views, inbox counts, and sheet headers.
- **Body:** Standard spacing ensures readability across varying task note lengths and multi-line item titles.
- **Labels & Priority Tags:** Semibold and bold weights paired with uppercase transforms (for tags) ensure quick visual scanning without dominating the task title.

## Layout & Spacing
The layout follows a mobile-first, single-column fluid model optimized for handheld touch zones.

- **Canvas Container:** Maximum mobile viewport container width of 480px centered on larger viewports.
- **Horizontal Margins:** Fixed `1rem` (16px) margins on narrow mobile devices, expanding to `1.25rem` (20px) on viewport widths above 400px.
- **Vertical Rhythm:** 
  - Standard spacing between consecutive task cards is `space-sm` (8px).
  - Section dividers (e.g., "Today", "Upcoming", "Completed") use `space-xl` (24px) top margin and `space-md` (12px) bottom margin.
- **Touch Targets:** Minimum interactive area of 44x44px for checkboxes, quick-add buttons, and filter chips.

## Elevation & Depth
Depth is created through ambient tinted drop shadows and clean white surface elevation over the `#F5F7FF` canvas.

- **Level 0 (Flat / Inactive):** Background tasks and resting cards use a 1px border of `#E2E8F0` and zero elevation.
- **Level 1 (Card Resting):** 
  - Background: `#FFFFFF`
  - Border: 1px solid rgba(226, 232, 240, 0.8)
  - Shadow: `0 2px 4px -1px rgba(79, 70, 229, 0.04), 0 4px 6px -1px rgba(30, 41, 59, 0.05)`
- **Level 2 (Active / Swiping / Modals):**
  - Shadow: `0 10px 15px -3px rgba(79, 70, 229, 0.08), 0 4px 6px -2px rgba(30, 41, 59, 0.04)`
- **Floating Action Bar / FAB:**
  - Shadow: `0 12px 24px -4px rgba(79, 70, 229, 0.35)`

## Shapes
The shape language uses distinct, generous radii that feel modern, organic, and inviting:

- **Cards & Sheets:** Use `rounded-2xl` (16px) for main task panels, modal bottom sheets, and summary dashboard cards.
- **Inner Elements:** Use `rounded-xl` (12px) for input fields, action buttons, and segmented control containers.
- **Micro Elements:** Use `rounded-lg` (8px) for priority badges, date tags, and category chips.
- **Checkboxes & FAB:** Checkboxes use `rounded-md` (6px) for an intentional rounded-square feel, while FABs and avatar bubbles are fully circular (`rounded-full`).

## Components

### Buttons
- **Primary:** Background `#4F46E5`, text `#FFFFFF`, font weight `600`, height 48px, `rounded-xl`. Active state applies scale(0.98) with `#4338CA`.
- **Secondary / Ghost:** Transparent background, text `#4F46E5`, 1px border `#E2E8F0`, background hover/touch `#EEF2FF`.

### Task Cards
- **Container:** Pure `#FFFFFF` background, `rounded-2xl`, Level 1 elevation, padding `12px 16px`.
- **Layout:** Flex row with checkbox pinned leading, followed by title, tags, and trailing due date or swipe handle.
- **Completed State:** Title receives line-through with color transitioning to `#64748B`; entire card drops opacity to 0.7.

### Checkboxes
- **Base:** 22x22px square with `rounded-md` (6px), 2px solid `#CBD5E1`.
- **Checked:** Background turns `#4F46E5`, border turns `#4F46E5`, displays crisp white checkmark SVG with spring animation.

### Priority Badges
- Compact chips rendered with `rounded-lg` (6px) padding `2px 8px`, `label-sm` font.
  - **High:** `#FFF1F2` surface, `#E11D48` text, subtle dot indicator `#F43F5E`.
  - **Medium:** `#FEF3C7` surface, `#D97706` text, subtle dot indicator `#F59E0B`.
  - **Low:** `#EFF6FF` surface, `#2563EB` text, subtle dot indicator `#3B82F6`.

### Input Fields & Quick-Add
- Height 48px, background `#FFFFFF`, border 1.5px solid `#E2E8F0`, `rounded-xl`, padding `0 16px`. Focus state shifts border to `#6366F1` with an outer glow of `0 0 0 3px rgba(99, 102, 241, 0.15)`.
- Placeholder color: `#94A3B8`.

### Filter Chips
- Pill-shaped (`rounded-full`) touch targets, height 32px, padding `0 14px`, `label-md`.
- Unselected: Surface `#FFFFFF`, text `#64748B`, border 1px solid `#E2E8F0`.
- Selected: Surface `#4F46E5`, text `#FFFFFF`, border 1px solid `#4F46E5`.
